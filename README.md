# The Next Step — TRIIBE × 上海联劝公益基金会（拟议合作概念）

这是独立学生测试原型，不是双方正式联合网站。没有已确认的合作、资助或官方背书。机构职责是拟议情境，正式使用前请与双方确认。未使用机构官方标识。

## 本地打开
直接双击 index.html 即可。无需 npm、安装依赖或构建。

## GitHub Pages 发布
1. 解压 ZIP，打开 TRIIBE-Lianquan-Website 文件夹。
2. 新建 GitHub repository（如 the-next-step）。
3. 将文件夹**里面的全部文件**上传到仓库根目录，确保 index.html 在根目录，不要再套一层文件夹。
4. Settings → Pages → Build and deployment → Deploy from a branch。
5. 选择 main 分支和 / (root)，点击 Save。
6. 等待 GitHub 部署，在 Pages 中点击 Visit site。

所有资源均采用相对路径，兼容 GitHub Pages 项目子路径。导航使用 hash 地址，可直接分享某一页面并刷新。

## 文件
- index.html：入口和元信息
- styles.css：完整响应式样式
- app.js：双语页面、导航、问答、申请、草稿及下载
- .nojekyll：禁用 Jekyll

## 功能与数据
中英文切换；桌面导航与手机折叠菜单；首页、项目介绍、流程、灵感、合作构想、FAQ、需求问答、三步申请；本地草稿、下载、清除。
申请信息保存在访客浏览器 localStorage 中，不发送到服务器，也不通知 TRIIBE 或联劝。清除浏览器数据会移除草稿。没有真实资金申请功能。
