# THE NEXT STEP — V4.1

## 打开网站
解压文件夹，双击 `index.html`。无需安装或运行后端。默认中文，右上角切换英文；浏览器会记住语言选择。

## 上传 GitHub Pages
1. 打开现有仓库，选择 Add file → Upload files。
2. 上传本文件夹里面的全部内容：index.html、styles.css、app-v4.js、tools.html，以及完整 assets 文件夹。
3. 文件名相同的会覆盖旧文件；app-v4.js 是本版主脚本，必须上传。
4. 确保 index.html 位于仓库根目录，assets 文件夹也在根目录，不要把图片拆散。
5. Commit changes，等 Pages 的 Actions 部署成功后刷新网站。

本版所有图片都在 assets 文件夹中，使用相对路径，不依赖远程图床或电脑本地路径。旧 app.js、app-photo-v14.js 不再被引用，无需修改它们。
